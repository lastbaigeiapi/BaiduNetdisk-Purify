百度网盘纯净补丁 · 方案应用工具

项目主页 https://github.com/lastbaigeiapi/BaiduNetdisk-Purify
下载工具 https://github.com/lastbaigeiapi/BaiduNetdisk-Purify/releases/latest/download/BaiduNetdisk-Purify-Setup.exe

一、适用环境
64 位 Windows 10 1809 及以上或 Windows 11。工具使用 Windows 自带的 .NET Framework。
官方客户端支持表列在项目主页，包括官方安装包下载地址和 SHA-256。8.10.3.103 仅适配官方 x64 安装包。
常规构建在检查兼容性时需要访问 raw.githubusercontent.com。还原时使用本机备份。

二、应用方案
1. 先安装支持表中相应的官方百度网盘，并等待正在进行的上传和下载结束。
2. 双击 BaiduNetdisk-Purify-Setup.exe。确认工具找到的安装目录，或手动选择包含 BaiduNetdisk.exe 的目录。
3. 检查兼容性。工具根据原始 core.asar 的 SHA-256 匹配方案，验证索引签名和方案文件。
4. 逐项勾选要移除的组件，再点「应用方案」。首次使用默认保留所有可选项目。选中的组件会移入安装目录的 nd_purify\removed。取消勾选后重新应用可放回对应备份。请保留 nd_purify 以便还原。
5. 完成后正常打开百度网盘。项目的后台提示处理器以当前用户权限运行。

三、使用上的变化
去掉广告、营销、搜索热词、AI 和办公等入口。网盘浏览、上传、下载、分享、转存及常用文件操作仍由官方客户端提供。
支持切换视频打开方式的方案默认勾选「在网盘内预览视频」。保留播放器组件后可使用内置预览，取消勾选并应用则下载后打开。
其他受支持文件下载后由系统默认应用打开。程序、脚本和压缩包在下载目录中定位。
删除后查找云端文件时，可使用网页版的回收站 https://pan.baidu.com

四、还原
运行同一个 EXE，确认原客户端目录后选择「还原客户端」。工具会核对本机备份，恢复核心文件、组件和自动更新设置，移除本项目的启动项。
用历史版本移除过 Windows 资源管理器右键菜单与同步覆盖图标的用户，可以用旧版补丁的卸载入口恢复该系统集成。

五、常见问题
- 无法下载方案。确认可以访问 raw.githubusercontent.com 后重试。
- 找不到匹配方案。请核对所装官方客户端的构建及官方安装包 SHA-256。
- 旧版安装器代码 1 且日志在 watcher 阶段显示拒绝访问。下载当前的方案应用工具，在原客户端目录重新应用。
- 安全软件报告 EXE。核对 GitHub 发布页的 SHA-256。当前分发 EXE 未做 Authenticode 代码签名，项目提供源码构建。
- 日志位于 %LOCALAPPDATA%\BaiduNetdiskPurify\applicator.log。
